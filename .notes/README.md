# .notes/ — Exploration scratch-pad

This directory holds informal findings, observations, and summaries as we explore the deepseek-harness repo. These are **not** formal Agent Notes (those live in `.agents/notes/` with lifecycle tracking). These are working notes — free-form, provisional, may be superseded.

## Convention

- **`<topic>.md`** — one file per topic we investigate
- First line: a date-stamped header like `# <Topic> — YYYY-MM-DD`
- Content: whatever we find — observations, code snippets, links to relevant source files, questions, TODO ideas
- These are scratch notes: update in place, append new findings at the bottom, never delete useful observations
- When a note is fully superseded by a deeper investigation, prefix its heading with `(superseded by <other>.md)`
